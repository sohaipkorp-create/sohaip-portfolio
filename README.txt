# Sohaip Kotp — Portfolio

## Files
- index.html — main portfolio page
- style.css — styling and responsive design
- script.js — navigation, year, and back-to-top button

## Before publishing
Open `index.html` and replace:
- GitHub placeholder link
- LinkedIn placeholder link
- Email placeholder

You can also add real GitHub links to individual projects later.

## Publishing with GitHub Pages
1. Create a GitHub account/repository.
2. Create a repository named `sohaip-portfolio` (or any name).
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the `main` branch and `/ (root)`.
7. Save and wait for GitHub to publish the site.
8. Your portfolio link will look like:
   https://YOUR-USERNAME.github.io/sohaip-portfolio/
